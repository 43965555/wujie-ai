PRJ-01-A · 内部系统

AI-CRM 系统

面向销售与客户运营的智能化 CRM，把客户数据、跟进话术、流失预警全部接入大模型能力。

核心功能
  • 360° 客户画像 — 整合交易记录、行为日志、客服对话、社交互动 4 类数据源共 200+ 维度，经统一 ID Mapping 后沉淀至客户 360 主题模型。基于 RFM 模型 + K-Means 聚类自动划分客户为 8 类价值层级，并结合 LightGBM 分类模型识别高价值客户与流失风险客户。
    STACK选 LightGBM 而非 XGBoost 的考量：200+ 维稀疏特征下推理延迟低 30%，原生支持 categorical feature 免去 one-hot 膨胀；ID Mapping 采用 Spark GraphX 离线匹配 + Flink 实时增量更新双链路，避免每日全量重算（节省 60% 计算资源）。
    FIX早期版本跨渠道数据合并出现"同人异 ID"错配率 8%，引入规则 + BiLSTM 孪生网络双判定后降至 0.3%；针对行为日志长尾稀疏问题，用对比学习预训练 customer embedding 再喂入聚类，冷启动客户分群准确率从 62% 提升至 87%。
    IMPACT某零售客户部署 6 个月，画像覆盖率 95%+，高价值客户识别准确率 92%；A/B 实验组（基于画像做精准推送）vs 对照组：复购率 +27%、客单价 +18%、营销 ROI 从 3.2 升至 5.8；2026 Q2 数据刷新从 T+1 优化至准实时（5 分钟）。
    ROLE8 人小组（2 算法 + 3 数据 + 2 后端 + 1 业务）任技术负责人，主导 ID Mapping 架构设计与 LightGBM 模型迭代；对接客户 CIO 与业务方把控需求边界与上线节奏。
  • 线索评分与排序 — 基于历史 10 万+ 成单数据训练 XGBoost 评分模型，提取线索来源、行为轨迹、企业属性、需求关键词等 50+ 特征，输出 0-100 分线索分值，自动分流至 A/B/C/D 四档优先级。结合实时行为事件流（浏览、留资、咨询）动态调整评分。
    STACK选 XGBoost 而非 DeepFM 的考量：特征工程透明、SHAP 可解释性强，便于销售侧建立信任（业务方一度抵制"黑盒深度模型"）；实时评分走 Flink + Redis HyperLoglog，事件流到分数更新 P95 延迟 < 2 秒。
    FIX训练-推理特征分布漂移问题（每月 AUC 下降 2-3%），引入 PSI 监控 + 自动触发重训 pipeline，漂移超阈值 24 小时内完成自动重训上线；冷启动期采用同行业历史数据迁移学习预训练，新行业接入首周即可达到 AUC 0.82。
    IMPACT某 B2B 客户销售人效提升 3 倍，线索转化率 +38%（A/B 对照）；模型从 v1 迭代到 v5，AUC 从 0.78 → 0.91；2026 H1 已扩展至制造 / SaaS / 教育 / 医疗 / 金融 6 个行业，跨行业迁移命中率 87%。
    ROLE5 人小组（2 算法 + 2 后端 + 1 数据工程）任技术负责人，主导特征工程体系与模型迭代；与销售总监共建线索分级 SOP，推动模型决策真正进入业务流程。
  • 跟进话术生成 — 结合客户 360 画像与所处销售阶段（认知/兴趣/对比/决策），基于 Qwen3-Max 微调模型实时生成个性化跟进话术，支持电话/微信/邮件三渠道文案输出。内置合规审核引擎，自动过滤违规承诺与敏感词，合规通过率 99.5%。
    STACK选 Qwen3-Max 私有化微调而非 GPT-4 API 的考量：金融/保险客户数据合规要求强制本地化，私有化部署 6 个月 TCO 较 API 调用下降 82%；微调走 LoRA + DPO 两阶段，业务方上传 5 万条优秀话术后 2 天内完成对齐。
    FIX早期话术"千篇一律"重复率 22%，引入客户画像 + 销售阶段条件 prompt + Top-p 0.85 采样调优后降至 4%；合规审核从规则引擎升级到 BERT 微调 + 规则双判定，覆盖"暗示保本""夸大收益"等 18 类违规模式。
    IMPACT某保险客户话术采纳率 78%，坐席人均产能 +2.5 倍；3 个月数据沉淀后模型从 base 升级到 v3，A/B 实验显示采纳率再 +15%；2026 Q2 接入实时对话上下文后，多轮跟进话术连贯性评分从 3.6 升至 4.4（满分 5）。
    ROLE6 人小组任技术负责人，主导模型微调 + 合规引擎设计；与客户法务/业务方共建合规白名单与审核 SOP，每周迭代违规模式规则库。
  • 流失预警与智能召回 — 采用 Survival Analysis 生存分析 + LSTM 时序预测双模型架构，基于客户近 90 天的行为衰减趋势、消费频次下降、客服投诉等 30+ 特征，提前 30 天预测流失风险与召回概率。系统自动触发分层召回 SOP（优惠/召回话术/专属服务）。
    STACK双模型而非单一架构的考量：Survival Analysis 擅长风险排序与可解释性（输出风险分数 + 置信区间），LSTM 擅长时序动态（捕捉行为衰减节奏），融合后 F1 较单模型提升 0.12；用 SHAP 输出 Top-5 流失归因，便于业务方理解。
    FIX长周期客户行为信号衰减问题，引入衰减加权 Attention（近 30 天权重 0.5、30-60 天 0.3、60-90 天 0.2），近因效应更显著；召回 SOP 早期"一刀切"问题升级到分层决策树（按客户价值 × 流失原因 × 历史响应偏好 12 条路径）。
    IMPACT某 SaaS 客户流失率 -45%，召回成功率 28%（行业基准 15%）；预警-召回闭环 T+0 自动触发，2026 Q2 接入 LLM 个性化召回话术后召回率再 +9%；累计挽回客户 LTV 估算超 ¥2.3 亿。
    ROLE7 人小组（含数据 + 算法 + 业务运营）任技术负责人，主导预警模型架构 + 召回 SOP 自动化引擎；与客户成功团队共建召回决策树与话术库。
  • 销售预测与漏斗分析 — 基于 Prophet 季节性分解 + 漏斗转化率建模，输出未来 90 天销售预测与置信区间，MAPE < 8%。支持按渠道/产品/区域/销售 4 维度交叉分析，自动识别漏斗瓶颈节点。结合归因模型（末次/首次/线性/数据驱动），输出每阶段转化率与改进建议。
    STACK选 Prophet 而非 LSTM 的考量：可解释性 + 训练成本低，业务方能直接理解趋势/季节/节假日分量；归因模型支持 4 种切换（末次/首次/线性/数据驱动 Shapley），不同业务场景灵活选择。
    FIX节假日与促销季预测失真问题（早期 MAPE 一度飙至 22%），引入事件特征 + 分段建模（日常 vs 大促分别训练），大促期 MAPE 降至 11%；漏斗瓶颈识别从规则升级到基于 Markov 链的归因，能识别"隐性漏斗"（多访问路径）。
    IMPACTMAPE < 8%（行业基准 15%）；某 3C 客户大促备货准确率 +22%，库存周转 +35%；2026 Q1 上线"预测-归因-建议"一体化看板，决策周期从周报缩短到日级响应。
    ROLE5 人小组任技术负责人，主导预测模型 + 归因算法 + 看板设计；与供应链/销售部门联合制定预测-备货-调拨联动 SOP。
  • 智能工单与客服辅助 — 工单基于 ModernBERT / BERT 微调模型自动分类路由至正确处理人，准确率 95%。坐席侧实时调用 RAG 知识库，基于对话上下文实时推荐答案与解决方案，首次响应解决率提升 35%。结合情绪识别模型，实时监测客户情绪波动并触发升级机制。
    STACK选 ModernBERT 而非 RoBERTa 的考量：多语言支持 + 8K 长上下文，跨境客户工单混杂中英日韩也能稳定分类；RAG 走 bge-m3 + Milvus 2.5 + Voyage Rerank 三段式，召回准确率较单段式 +14%。
    FIX客服对话长上下文遗忘问题，引入滑动窗口 + 历史摘要压缩，10 轮以上多轮对话仍保持 92% 上下文命中率；情绪识别早期"中性偏多"问题，加入 Focal Loss + 少数类数据增强后负面情绪召回率从 51% 升至 84%。
    IMPACT首次响应解决率 +35%，平均工单时长 -40%，CSAT 4.6/5（行业基准 4.2）；2026 H1 接入实时意图识别后转人工率再 -18%，单坐席日均工单处理量从 38 升至 67。
    ROLE8 人小组（含 NLP + 全栈 + UX）任技术负责人，主导分类模型 + RAG 体系 + 情绪识别模型；与客服运营共建知识库更新机制，每月新增 FAQ 自动入库。

PRJ-01-B · 内部系统

AI-知识库系统

企业级知识中台，自研 RAG 管线与知识图谱自动构建，让组织知识沉淀、可检索、可复用。

核心功能
  • 多源知识自动入库 — 支持 PDF/Word/Excel/PPT/Confluence/飞书/Notion/SharePoint 等 20+ 数据源接入，API 实时同步 + 定时全量校验双链路保障一致性。基于 DocLayout-YOLO + LayoutLMv4 版面分析精准识别标题/段落/表格/图片/公式 5 类元素，表格结构化还原准确率 95%，配合 LLM 语义分块 + 滑动窗口，日均处理 10 万+ 文档。
    STACK选 DocLayout-YOLO 而非纯 LayoutLMv4 的考量：YOLO 路线推理速度快 3 倍（单页 P95 180ms），版面框选边界更精确；LayoutLMv4 仅在表格/公式场景作补充。OCR 走 PaddleOCR 而非 Tesseract，中文识别 F1 高 18%；分块策略选 LLM 语义分块而非固定窗口，避免切断语义单元，下游检索召回 +9%。
    FIX早期 PDF 双栏排版识别错位率 14%，引入版面行列聚类 + 阅读顺序模型后降至 1.2%；飞书/Notion 增量同步丢字段问题，改用 CDC（Change Data Capture）+ 全量校验双链路，字段缺失率从 3.8% 降至 0.05%；表格合并单元格识别引入 Cross-Line Cell Merging 算法，复杂表头还原 F1 从 0.71 升至 0.93。
    IMPACT日均入库 12 万文档（v1 仅 2 万），入库准确率从 89% 升至 98.2%；某金融客户部署 3 个月知识沉淀总量 +4 倍，运营人力从 8 人降至 2 人；2026 Q1 上线增量 CDC 后跨源同步延迟从 T+1 优化至 5 分钟内，知识新鲜度大幅提升。
    ROLE10 人小组（2 算法 + 3 后端 + 2 数据 + 2 前端 + 1 业务）任技术负责人，主导版面分析模型选型 + 多源同步架构；与 IT 部门共建接入 SOP，30 天内完成 20+ 数据源对接。
  • RAG 语义检索问答 — 采用 bge-multilingual-gemma2 向量化 + Milvus 2.5（Sparse-Dense 混合检索）+ Voyage Rerank 2 三段式架构，支持向量 + 关键词 + BM25 三路融合检索。P95 响应延迟 < 800ms，Top-5 召回率 92%，问答准确率 94%，支持多轮上下文理解、答案溯源、流式输出，日均服务 50 万+ 查询。
    STACK选 bge-multilingual-gemma2 而非 OpenAI text-embedding-3 的考量：私有化部署合规可控，多语言混合检索效果不输 OpenAI；Milvus 2.5 选 IVF-Sparse + Dense 双索引，亿级向量查询 P95 < 200ms；Rerank 选 Voyage Rerank 2 而非 bge-reranker，长文档相关性判别 NDCG@5 高 6%。
    FIX长查询语义漂移问题，引入 Query Rewrite + HyDE 假设文档生成，召回率从 78% 提升至 92%；多轮对话上下文丢失，采用 Contextual Retrieval（每轮重新构造 query 上下文），10 轮以上对话命中率从 64% 升至 89%；冷启动领域词表缺失，融合业务术语词典 + 同义词扩展，专业领域问答准确率 +12%。
    IMPACT某制造业客户日均查询 50 万次，P95 延迟从 1.6s 降至 720ms；A/B 实验组 vs 关键词检索：问答采纳率 +35%、人工二次检索率 -42%；2026 Q2 引入 Rerank 2 后 Top-1 命中率从 71% 升至 84%；模型迭代 v1→v4，准确率 78%→94%。
    ROLE8 人小组（3 算法 + 2 后端 + 2 数据工程 + 1 业务）任技术负责人，主导 RAG 三段式架构与 HyDE 优化；与知识管理部共建评测集（5000 题），每两周迭代一次。
  • 知识图谱自动构建 — 基于 UIE 通用信息抽取 + LLM Few-shot 抽取双链路，从非结构化文档中抽取实体（人/物/事/地/组织）与关系（归属/因果/时序），融合 Cross-Document Coreference Resolution 跨文档共指消解，自动构建本体图谱。图谱规模百万节点 + 千万边，支持多跳推理问答，复杂关系问答准确率 85%+。
    STACK选 UIE + LLM 双链路而非纯 LLM 抽取的考量：UIE 在结构化领域召回稳定且成本低，LLM 兜底长尾与复杂关系；图存储选 NebulaGraph 而非 Neo4j 的考量：千亿边规模下查询延迟低 60%；推理引擎选 OpenSPG 而非自研，可解释性强且兼容业务规则注入。
    FIX早期 LLM 抽取幻觉率 18%，引入 Schema 约束 + Self-Consistency 多次采样投票后降至 3.5%；跨文档共指消解错配率 9.8%，加入实体别名表 + 上下文消歧模型后降至 1.2%；图谱爆炸式增长（月增 300 万边）导致查询变慢，引入子图压缩 + 热点索引，多跳查询 P95 从 4.2s 降至 0.8s。
    IMPACT某能源客户图谱沉淀 280 万实体 + 4200 万关系，多跳问答准确率 85%（基线 BM25 仅 41%）；A/B 实验组 vs 关键词检索：复杂关系查询命中率 +52%；2026 H1 上线"图谱 + RAG"联合推理后，业务推理类问题准确率从 67% 升至 88%。
    ROLE7 人小组（3 算法 + 2 图数据库 + 1 后端 + 1 业务）任技术负责人，主导抽取双链路与共指消解算法；与业务专家共建本体 Schema，每月迭代领域关系定义。
  • 文档智能解析与摘要 — DocLayout-YOLO + LayoutLMv4 版面分析 + Donut 文档理解 + LLM 长文档分块摘要三层架构，支持 100 页+ 长文档。结构化输出大纲、关键信息、表格数据，一键生成执行摘要；配合公式识别（LaTeX 输出）与图片描述，文档理解完整度 95%+。
    STACK选 Donut 而非纯 OCR + 规则的考量：端到端文档理解免去 OCR 后处理流程，复杂版式 F1 高 22%；摘要走 Qwen3-Max 长上下文模型而非分段摘要拼接，全文一致性更优；公式识别选 LaTeX-OCR 而非 MathPix API，私有化部署满足合规且成本下降 90%。
    FIX长文档 LLM 上下文截断问题，引入 Hierarchical Summarization（先段落后全局融合），100 页文档摘要一致性评分从 3.1 升至 4.4；跨页表格断行识别错误率 12%，加入版面连续性推断 + 表格跨页合并算法后降至 1.5%；公式混合排版误检，引入版式分类前置 + 公式区域二次校验，F1 从 0.78 升至 0.94。
    IMPACT某律所客户合同解析准确率 96%，律师审阅效率 +3 倍；100 页文档摘要生成耗时从 45 秒压缩至 8 秒；2026 Q2 引入 Donut v2 后表格还原 F1 从 0.88 升至 0.95；A/B 实验组 vs 人工摘要：信息完整度持平、节省 95% 人力。
    ROLE6 人小组（2 算法 + 2 后端 + 1 前端 + 1 业务）任技术负责人，主导版面分析 + 分层摘要架构；与法务/研发部门共建文档解析 SOP 与评测集。
